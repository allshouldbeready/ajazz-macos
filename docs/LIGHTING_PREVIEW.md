# Lighting preview

The Lighting page renders the AK820 Pro as interactive interface elements.
Selecting a mode or adjusting its colour, brightness, speed, or direction updates
the preview immediately. Click keys or type while the preview is focused to try
the reactive effects. Applying settings to the keyboard remains a separate action.

The geometry follows the ANSI product photograph, including its knob, navigation
column, offset arrows, and square display. The colour selector includes the
Grey, White Purple, and Grey Beige Red finishes listed on the
[Epomaker AK820 Pro product page](https://epomaker.com/products/ajazz-ak820-pro).
Switch choices do not change the exterior. Product photographs are references;
no vendor photograph is bundled with the application.

These animations illustrate the effect catalogue. Exact firmware animation
curves and timing have not been measured for every hardware revision, so the
preview is not a frame-exact recording of the keyboard.

User hardware observations on 13 September 2026 refined three reactive modes:
Launch produces two approximately one-key-wide vertical bars travelling left and
right from the pressed key. Ripples uses a roughly half-keyboard-width lit band
followed by an outward off wave; the full cycle takes 0.8 seconds at default
speed. Explode spreads along the bottom LED gap of the pressed row before fading.

The miniature display plays locally remembered frames from a successful upload.
Older application versions stored only an upload label; they cannot reconstruct
the original animation from that label or read it back from the keyboard.
